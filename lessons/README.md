# Lesson sources

The built-in lessons, as MuseScore 4 scores. These `.mscz` files are the
sources. The `.musicxml` files the app ships in
`app/src/main/assets/packs/builtin/` are exported from them, as are the
reference renders in `builtin/renders/`. Lesson details (titles, tempo
ranges, descriptions, tips) live in that folder's `pack.json`.

How lessons are written and exported: [`docs/lessons.md`](../docs/lessons.md).
